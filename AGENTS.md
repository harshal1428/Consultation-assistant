# VoiceSurg Repository Rules

These rules are mandatory for every contributor and agent working in this repository.
Re-read this file at the start of every session.

1. **Create and follow AGENTS.md.** This file contains all repository rules. Re-read it at the start of every session.
2. **`backend/tests/gold/utterances.csv` is READ-ONLY.** Never edit, reformat, re-save, or "fix" it. Never edit existing tests to make anything pass. Add new tests instead.
3. **Never guess file names, schemas, or APIs.** Search the repository and read the real code before making changes.
4. **Only free and open-source tools.** No paid or closed services. Do not commit model weights, audio files, or secrets.
5. **Run backend pytest and frontend Vitest before saying anything is done.** Commit after each green step with a clear message.
6. **If blocked or an assumption is risky, write it in the final report** instead of silently choosing.
7. **No bundled face or head geometry may be added.**
